# FlowTech

بوت واتساب مع لوحة تحكم لإدارة الربط والإعدادات والأوامر.

## التشغيل

يتطلب Node.js 20 أو أحدث.

```bash
npm install
npm start
```

يفتح الموقع على المنفذ المحدد في `PORT`، ويستخدم `0.0.0.0` افتراضيًا ليتوافق مع الاستضافات.

## قبل النشر

1. راجع إعدادات `.env` واضبط `DASHBOARD_SECRET` بقيمة طويلة وعشوائية.
2. أضف مفاتيح خدمات الذكاء الاصطناعي عند الحاجة؛ وهي غير مضمنة في المشروع.
3. اربط تخزينًا دائمًا بالمسار المحدد في `DATA_DIR` حتى لا تفقد جلسة واتساب عند إعادة تشغيل الاستضافة.
4. شغّل نسخة واحدة فقط لكل جلسة واتساب.

## القائمة والأوامر

أرسل `.اوامر` لعرض الأقسام التسعة، ثم أرسل رقم القسم لعرض أوامره. لعرض القائمة الكاملة استخدم `.كل_الأوامر_الكاملة`.

## البحث والتنزيل

- `.موسيقى اسم الأغنية`
- `.يوتيوب عبارة البحث`
- `.تحميل رابط`
- `.apk اسم التطبيق` للبحث في مستودع F-Droid الرسمي
- `.بلاي اسم التطبيق` للبحث في Google Play

تحتاج أوامر تنزيل الوسائط إلى `yt-dlp` وPython وFFmpeg، إذا كانت الاستضافة تسمح بتثبيتها. يعتمد نجاح التنزيل على توفر المحتوى ودعم المصدر.

## ملفات البيانات

يُستخدم مجلد `data` لحفظ الجلسات والبيانات. لا تحذفه بعد ربط واتساب. يجب حفظه على قرص دائم في الاستضافة.
